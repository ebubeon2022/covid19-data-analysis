# COVID-19 Data Analysis with Python

A beginner-friendly Jupyter Notebook project analysing a supplied COVID-19 cases dataset.

## Files
- `COVID-19_Data_Analysis.ipynb` — questions followed by Python solutions and outputs when you run the notebook.
- `COVID-19 Cases World.csv` — source dataset.

## Run it
1. Install Python and Jupyter Notebook (or use VS Code with the Jupyter extension).
2. Install the required packages:
   `python -m pip install pandas matplotlib`
3. Open `COVID-19_Data_Analysis.ipynb`.
4. Keep the CSV in the same folder as the notebook.
5. Select **Run All**.

## Data note
The notebook analyses the supplied dataset and is not a source of current COVID-19 statistics. The brief asks for “death rates by continent,” but the supplied CSV has reported death counts rather than a separate death-rate column, so the notebook sums reported deaths by continent.
